# Remove Background

Menghapus latar belakang gambar dan menyediakan editor untuk memperbaiki bagian yang masih keliru. Hasil akhirnya dapat dipakai sebagai gambar transparan pada desain lain.

## Cara mulai

1. Pilih tab **Upload** dan tambahkan JPG/PNG/WebP maksimal 12 MB, atau gunakan tab **URL** untuk tautan file gambar langsung.
2. Jika **AI otomatis setelah upload** aktif, tunggu prosesnya. Jika tidak, tekan **Proses**.
3. Baca status sampai hasil benar-benar siap.
4. Gunakan **Bandingkan** untuk melihat sumber dan hasil.
5. Jika sudah bersih, tekan **Download**.
6. Jika ada bagian hilang atau latar tersisa, buka **Edit manual / rapikan hasil**.

Tautan dari halaman postingan atau hasil pencarian belum tentu merupakan file gambar langsung. Bila URL gagal, coba unggah file dari perangkat.

## Merapikan hasil dengan editor

| Alat | Kegunaan |
| --- | --- |
| **Hapus** | Menghilangkan area yang disapu kuas. |
| **Pulihkan** | Mengembalikan bagian gambar yang terhapus. |
| **Hapus area** | Menghapus area dengan pertimbangan toleransi yang dipilih. |
| **Geser** | Menggerakkan tampilan saat diperbesar. |
| **Ukuran kuas** | Lebar sapuan. Kecil untuk detail, besar untuk area luas. |
| **Ketegasan** | Keras atau lembutnya batas kuas. |
| **Toleransi area** | Seberapa luas kemiripan area yang dijangkau alat penghapusan area. |
| **Undo / Redo** | Membatalkan atau mengulang koreksi. |
| **Rapikan tepi** | Membantu menipiskan sisa tepi dengan pilihan yang tersedia. |
| **Terapkan hasil** | Menggunakan koreksi editor pada hasil yang akan disimpan. |

Contoh: jika bagian rambut ikut hilang, pilih Pulihkan dengan kuas kecil. Jika ada sisa latar di antara lengan dan badan, perbesar tampilan lalu Hapus perlahan.

## Preview bukan warna file

Latar **Transparan / Putih / Hitam** membantu memeriksa tepi objek. Mengubah latar pemeriksaan tidak sama dengan mengganti latar file hasil menjadi warna tersebut.

Gunakan +/− atau Pas layar untuk navigasi. Setelah selesai merapikan, Terapkan hasil lalu periksa unduhan, bukan hanya preview editor.

## Jika bermasalah

Tunggu proses sebelumnya selesai sebelum menambahkan pekerjaan baru. Jika input rusak atau terlalu besar, pilih gambar yang sesuai batas. Jika koreksi kurang tepat, gunakan Undo, Redo, atau Ulang koreksi sebelum menerapkannya.

Hasil otomatis tetap perlu diperiksa, terutama rambut halus, kaca, bayangan, dan objek yang warnanya mirip latar.
