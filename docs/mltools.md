# ML Tools Nexora

Kumpulan utilitas Mobile Legends dengan tiga menu: pencarian script, kalkulator winrate, dan pencarian profil MLBB.

## Script ML

1. Pilih **Script ML**.
2. Isi **NAMA HERO**, misalnya “Fanny”.
3. Tekan **CARI SCRIPT**.
4. Baca tautan hasil dan sumber yang ditampilkan.

Jika penyedia utama tidak tersedia, halaman dapat menampilkan tautan pencarian web alternatif. Itu bukan bukti file script sudah tersedia atau sudah diunduh.

Tool ini menampilkan hasil pencarian; ia tidak otomatis memasang script ke game atau menjamin isi tautan eksternal.

## Winrate: hitung target kemenangan

1. Pilih **Winrate**.
2. Isi **TOTAL MATCH**.
3. Isi **WR SEKARANG** dalam persen.
4. Isi **TARGET WR** yang ingin dicapai.
5. Tekan **HITUNG WINRATE**.

Contoh: 100 match, WR sekarang 50, target 60. Jika setiap pertandingan berikutnya menang, diperlukan 25 kemenangan tambahan untuk menjadi 75 kemenangan dari 125 match.

Jika ada kekalahan baru, hitung ulang dengan total dan WR terbaru. Jika target sudah tercapai atau masukan tidak masuk akal, baca keterangan hasil alih-alih memaksakan angka.

**Perhatikan:** kalkulator FF Tools meminta jumlah kemenangan, sedangkan menu ML ini meminta persentase WR sekarang.

## Stalk MLBB

1. Buka **Stalk MLBB**.
2. Isi **USER ID** dan **ZONE ID** sesuai profil pemain.
3. Tekan **CEK AKUN**.
4. Baca informasi profil yang tersedia.

Zone ID adalah kode server/zone akun yang biasanya ditampilkan bersama User ID. Jangan menggabungkannya sembarang ke kolom yang sama; formulir menyediakan dua kolom.

## Hasil dan kendala

Data akun mengikuti penyedia. Jika tidak ditemukan, periksa salah ketik User ID dan Zone ID. Jika hanya tautan pencarian alternatif yang tersedia pada Script ML, baca labelnya sebagai alternatif pencarian, bukan hasil file yang sudah diverifikasi.

Fitur ini tidak mengubah statistik, menambah kemenangan, atau masuk ke akun game.
