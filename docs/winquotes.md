# Windows Quotes

Membuat gambar kutipan bergaya Windows dengan dua pilihan tampilan. Teks dapat dibagi menjadi beberapa baris memakai tanda **|**.

## Cara pakai

1. Pilih **Style 1** atau **Style 2**.
2. Isi kolom teks.
3. Untuk beberapa baris, pisahkan tulisan dengan tanda |.
4. Tekan **Generate**.
5. Periksa gambar.
6. Tekan **Download PNG** atau **Copy URL**.

Contoh isian:

> tetap belajar|pelan-pelan|yang penting|terus jalan

Tanda | berfungsi sebagai pemisah baris untuk layanan gambar ini. Menulis satu kalimat tanpa tanda tersebut menghasilkan susunan yang berbeda.

## Hasil dan kendala

Style mengganti tampilan gambar, bukan isi kata-katanya. Setelah berpindah Style, Generate ulang agar hasil mengikuti pilihan terbaru.

Copy URL menyalin alamat hasil, bukan menyimpan file ke galeri. Jika butuh file, gunakan Download PNG.

Pembuatan memakai penyedia online. Jika preview tidak muncul, periksa koneksi atau tunggu layanan pulih. Mulai dari kutipan pendek agar tulisan lebih mudah terbaca.
