# Nexora Image HD Enhancer V4

Meningkatkan kualitas gambar melalui layanan online. Input bisa berupa file galeri atau tautan file gambar langsung.

## Cara pakai

1. Buka **Nexora Image HD Enhancer V4**.
2. Pilih **Upload** untuk JPG/PNG/WebP maksimal 12 MB, atau **URL** untuk tautan gambar.
3. Pastikan preview sumbernya benar.
4. Tekan **Proses**.
5. Tunggu hasil selesai dan baca informasi ukuran atau skala.
6. Gunakan **Bandingkan** untuk melihat perubahan.
7. Tekan **Download** untuk menyimpan hasil.

Contoh: unggah foto produk yang kecil, proses, lalu periksa tulisan label dan tekstur sebelum menggunakan hasil untuk katalog.

## Cara membaca hasil

**Peningkatan kualitas** dan **pembesaran dimensi** tidak selalu sama. Gambar dapat terlihat lebih bersih tanpa jumlah pikselnya bertambah.

Antarmuka memeriksa ukuran input/output jika informasinya tersedia. Pesan **Upscale terverifikasi** berarti dimensi pembesaran telah diperiksa. Pesan bahwa skala menunggu verifikasi berarti jangan langsung menganggap hasil sudah diperbesar dengan kelipatan tertentu.

Jangan menyimpulkan semua gambar menjadi 4× hanya dari nama HD. Untuk kontrol 2× atau 4× yang jelas, gunakan [Perbesar Gambar 4x](bigjpg-nexora.md).

## Tombol dan kendala

- **Bandingkan:** memeriksa sumber dan hasil; tidak memproses ulang.
- **Download:** mengambil hasil yang sudah tersedia.
- **Gambar lain:** menyiapkan input baru.
- **Batalkan proses:** menghentikan penantian yang ditangani halaman.

Jika URL gagal, pastikan tautan membuka file gambar, bukan halaman web. Jika layanan tidak tersedia atau memberi batas permintaan, baca pesan dan tunggu sebelum mencoba lagi.
