# Logo Animate

Menyiapkan template XML animasi logo untuk Alight Motion dengan teks pendamping. Template menyertakan media contoh yang nantinya diganti di Alight Motion.

**Logo tidak diunggah melalui formulir ini.** Tahap mengganti media dilakukan setelah XML diimpor.

## Cara pakai dari awal sampai akhir

1. Isi **Teks pendamping**, misalnya nama merek.
2. Pilih **Warna teks**.
3. Pilih **Font template** dari daftar yang tersedia.
4. Biarkan **Tambahkan teks ke template** aktif jika ingin tulisan ikut disertakan.
5. Isi nama proyek dan nama file jika diperlukan.
6. Tekan **Generate XML**, lalu unduh hasil yang tersedia.
7. Impor XML ke Alight Motion.
8. Temukan media logo placeholder pada proyek hasil.
9. Ganti media tersebut dengan gambar logomu sendiri.
10. Putar proyek untuk memeriksa ukuran, posisi, dan gerakan sebelum mengekspor video.

## Pengaturan yang perlu dipahami

- **Teks pendamping:** tulisan yang ikut ditempatkan dalam template.
- **Font template:** font yang disediakan template, bukan unggah sembarang font.
- **Tambahkan teks ke template:** jika dimatikan, teks pendamping tidak ditambahkan melalui pilihan ini.
- **Nama project Alight Motion:** nama di dalam proyek.
- **Nama file download:** nama berkas XML yang disimpan.

Template aslinya berdurasi sekitar 8,33 detik. Engine menyatukan bagian-bagian template menjadi satu XML proyek, bukan tiga file yang perlu digabung sendiri. Simpan XML tersebut lalu periksa hasil impornya.

## Contoh dan kendala

Untuk logo toko, isi teks “TOKO NEXORA”, Generate, lalu ganti media logo bawaan dengan PNG logo toko di Alight Motion. Jika hasil impor masih menampilkan media contoh, itu berarti tahap penggantian media belum dilakukan.

Riwayat hasil tersimpan lokal. Jika Download All memulai beberapa unduhan, izinkan unduhan jamak jika browser meminta. Tool ini tidak langsung mengekspor MP4; video final diekspor dari Alight Motion.
