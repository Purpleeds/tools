# 3D Text Animate

Membuat XML teks bergaya tiga dimensi untuk Alight Motion. Efek dibangun melalui template gerak, ketebalan, lapisan warna, dan bayangan.

## Cara mulai

1. Isi teks pendek, misalnya “NEXORA”.
2. Pilih **Preset 3D: Flip 3D** untuk percobaan pertama.
3. Pilih Timing target per karakter atau per kata.
4. Gunakan font serta ukuran bawaan dahulu.
5. Periksa warna pada **Color roles**.
6. Tekan Generate XML, unduh, lalu impor ke Alight Motion.

Tool menghasilkan proyek XML, bukan model 3D seperti OBJ atau file video.

## Pilihan preset

| Preset | Arah tampilan |
| --- | --- |
| **Flip 3D** | Gerakan membalik dengan kesan tiga dimensi. |
| **Right** | Variasi gerakan arah kanan. |
| **Popup Rotate Extrude** | Tampilan muncul dengan rotasi dan ketebalan. |
| **Long Shadow** | Penekanan bayangan panjang. |
| **Offset Kosongan** | Variasi pergeseran lapisan. |
| **Offset Orange Style** | Variasi offset dengan gaya oranye. |
| **Offset Green Fire** | Variasi offset dengan gaya hijau. |

## Pengaturan penting

- **Timing target:** gerakan per karakter atau per kata.
- **Graph preset:** pola laju gerakan, seperti Smooth, Linear, atau pilihan acak.
- **Extrude / Depth (%):** arahan ketebalan atau kedalaman efek.
- **Border:** mengaktifkan tepi sesuai preset.
- **Link font size & spacing:** saat aktif, perubahan ukuran font ikut menyesuaikan jarak.
- **Spacing / Line gap:** jarak antarhuruf dan antarbaris.
- **Stagger:** jeda mulai antarbagian.
- **Last Start:** pengaturan waktu mulai terakhir pada susunan animasi.
- **End Hold:** waktu hasil bertahan setelah gerakan.
- **X Position / Y Position:** pengaturan posisi; mulailah dari nilai bawaan sebelum bereksperimen.

## Mengatur warna

Color roles berubah mengikuti preset. Sebuah preset dapat memiliki warna permukaan, tepi, atau bayangan yang berbeda. Jangan menganggap satu warna mengubah seluruh hasil.

Pilih palet untuk mengisi peran warna, lalu sesuaikan warna tertentu bila diperlukan. Riwayat dan palet custom disimpan lokal, bukan sebagai proyek yang otomatis tersinkron ke semua perangkat.

## Hasil dan kendala

Generate ulang setelah mengubah preset atau warna. Jika tulisan terlalu panjang atau posisi kurang sesuai, periksa jarak dan ukuran pada proyek hasil di Alight Motion. Nama file berbeda dari nama proyek di dalam XML.

Preview web bukan simulasi lengkap seluruh efek Alight Motion. Simpan XML yang disukai dari Download atau riwayat lokal.
