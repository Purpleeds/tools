# Nokia Message

Membuat gambar pesan dengan tampilan Nokia klasik. Semua isian menjadi bagian gambar; tool tidak mengirim SMS sungguhan.

## Cara pakai

1. Isi **Pesan**.
2. Isi **Dari** sebagai nama pengirim pada gambar.
3. Isi **Judul**.
4. Periksa **Tanggal** dan **Jam**; nilai awal mengikuti waktu perangkat ketika formulir dibuka.
5. Tekan **Generate**.
6. Periksa preview, lalu pilih Download PNG atau Copy URL.

Contoh:

- Pesan: “Jangan lupa istirahat.”
- Dari: “Nexora”.
- Judul: “Pengingat”.

## Memahami hasil

Dari bukan nomor tujuan SMS. Tanggal dan Jam merupakan teks pada tampilan pesan, bukan jadwal pengiriman.

Gunakan pesan singkat agar sesuai dengan layar ponsel klasik pada template. Jika mengubah teks, waktu, atau nama, Generate ulang sebelum mengunduh.

Copy URL hanya menyalin tautan gambar. Jika layanan pembuat gambar belum merespons atau hasil kosong, belum ada gambar baru yang bisa disimpan.
