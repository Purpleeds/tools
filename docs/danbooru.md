# Danbooru Search

Mencari ilustrasi anime memakai **tag**, yaitu kata penanda isi gambar. Pencarian tidak berjalan otomatis saat mengetik; tekan Search untuk menjalankannya.

## Cara mencari

1. Isi **Search tags**.
2. Untuk awal, gunakan **Mode: Safe**.
3. Tekan **Search**.
4. Buka gambar dari galeri untuk melihat preview dan informasi.
5. Gunakan Open Image, Copy Image Link, atau Download jika pilihan itu tersedia pada hasil.

Contoh tag: **hatsune_miku**. Banyak nama karakter memakai garis bawah sebagai pengganti spasi. Coba tag tunggal yang jelas sebelum membuat kombinasi yang panjang.

## Memahami pilihan

**Safe** adalah pilihan awal untuk hasil aman sesuai penilaian sumber. **NSFW** meminta kategori lain yang tersedia pada integrasi dan tetap mengikuti aturan sumber serta akses Nexora.

Nama karakter atau tag harus sesuai penamaan sumber. Kalimat panjang seperti permintaan AI tidak otomatis menjadi prompt pembuat gambar; tool ini mencari gambar yang sudah tersedia.

## Jika hasil kosong

Periksa ejaan tag, kurangi kombinasi, dan coba satu nama karakter. Tidak semua hasil memiliki gambar penuh atau metadata lengkap.

Download dapat bergantung pada tautan dan pembatasan sumber. Jika tautan gambar tersedia tetapi unduhan langsung tidak berhasil, gunakan Open Image lalu pilihan simpan browser jika didukung.

Untuk menjelajahi ilustrasi dan GIF berdasarkan beberapa sumber, lihat [Anime Discover](animegallery.md).
