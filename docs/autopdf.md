# Nexora Auto PDF

Menyusun tulisan menjadi PDF dengan pembagian halaman otomatis. Cocok untuk cerita, catatan, materi, atau tulisan yang memiliki beberapa bagian.

## Cara pakai

1. Isi judul bagian dan tempel teksnya.
2. Gunakan **Tambah bagian** jika ada bab atau bagian berikutnya.
3. Pilih kertas **A5** atau **A4**.
4. Pilih font **Helvetica** atau **Times Roman**.
5. Atur ukuran font, jarak baris, dan margin jika perlu.
6. Tekan **Buat Preview**.
7. Periksa pergantian halaman dan paragraf.
8. Isi **Nama file**, lalu tekan **Unduh PDF** ketika preview siap.

Jika teks atau pengaturan diubah setelah preview dibuat, buat preview lagi agar hasil unduhan sesuai isi terbaru.

## Memilih pengaturan

| Pilihan | Panduan sederhana |
| --- | --- |
| **A5** | Halaman lebih ringkas, cocok untuk bacaan seperti novel kecil. |
| **A4** | Halaman lebih luas, umum untuk dokumen. |
| **Helvetica** | Tampilan huruf bersih dan modern. |
| **Times Roman** | Tampilan lebih klasik atau formal. |
| **Ukuran font** | Ukuran tulisan; rentang formulir 8–18. |
| **Jarak baris** | Jarak antarbaris; lebih besar membuat bacaan lebih renggang. |
| **Margin (pt)** | Ruang kosong di tepi halaman. |
| **Mulai setiap bagian di halaman baru** | Membuat bab atau bagian dimulai pada halaman sendiri. |

## Contoh dan hasil

Masukkan “BAB 1” sebagai judul, isi ceritanya, lalu Tambah bagian untuk “BAB 2”. Aktifkan halaman baru per bagian jika setiap bab ingin dimulai terpisah.

Pembuatan PDF berjalan di perangkat dan file dapat langsung diunduh. Tool ini menyusun teks, bukan menganalisisnya dengan AI atau menyalin tata letak PDF lama.

Jika ada karakter yang tidak dapat diproses font, periksa pesan dan ganti karakter tersebut atau gunakan tulisan yang didukung. Simpan PDF sebelum Reset atau menutup tool. Untuk menggabungkan PDF yang sudah jadi, gunakan [PDF Lab Local](pdflab.md).
