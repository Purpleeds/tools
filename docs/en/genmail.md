# GenMail

Creates a temporary email address for receiving messages and codes, then lets you read the inbox from Nexora. This tool is not a service for sending outgoing email.

## Creating an address

1. Open **GenMail** and wait for the domain options to finish loading.
2. Fill in **Username** if you want a specific name, for example "latihannexora".
3. If you want a random name, leave Username empty.
4. Choose a **Domain**.
5. Press **Generate Email**.
6. Use **Copy Email** to copy the full address.

Don't copy only the username; an email address also needs the domain part after the @ sign.

## Reading messages

1. Use the address with the service you want to try.
2. Go back to GenMail.
3. Press **Open Inbox** or the Inbox tab.
4. Press **Refresh Inbox** to check for the latest messages.
5. Tap a received message to read it.
6. Use **Kembali ke inbox** (Back to inbox) to return to the list.

The inbox doesn't update every second. If a message hasn't arrived, wait and then Refresh as needed. Don't resend codes too often from the originating service.

## Understanding New Email

The **New Email** tab is the panel for creating an address. Check the active address before creating a new one; opening the tab and actually generating a new address are two different things.

The active address is only kept for the same session/tab, according to how this feature manages it. Don't assume the address, its messages, and access to it are available permanently.

## If it fails

If the domains haven't loaded, wait or use Coba lagi (Try again). If a name can't be used, try another username or the random option. If the inbox is empty, check the destination address and make sure the originating service has actually sent the email.

Use a primary email you control for important accounts. This tool is mainly useful for temporary needs, because the availability of addresses and messages depends on the provider.
