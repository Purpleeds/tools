# IP & ASN Intelligence

Looks up general network information for an IPv4 or IPv6 address: the ASN, organization, country, and continent available from the IPinfo Lite service.

## How to use it

1. Enter one IP address, for example 8.8.8.8 as an IPv4 example.
2. Press **ANALISIS IP** (ANALYZE IP).
3. Read the organization, ASN, and general location information.
4. Use **IP SAYA** (MY IP) if you want information about the public address the service sees.
5. Use Hapus (Clear) to change the input.

This field accepts an IP address, not a full website URL. To check a website, use [Web Intelligence](webintel.md).

## Simple terms

- **IPv4 / IPv6:** two ways of writing network addresses.
- **ASN:** a network number belonging to a provider or organization.
- **Organization:** the network name recorded by the data provider.
- **Country / continent:** the general location associated with that network.

## Example and limits

If you use a VPN, IP SAYA (MY IP) may show the VPN's exit network. If you use a mobile carrier connection, the information may point to the carrier or a shared network, not directly to your home location.

The result is not tracking of a private address, a user's name, or exact home coordinates. If an IP can't be processed, check its format. Private addresses or data the service doesn't know may give limited results.
