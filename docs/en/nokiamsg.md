# Nokia Message

Creates a message image with a classic Nokia look. Everything you enter becomes part of the image; the tool doesn't send a real SMS.

## How to use it

1. Fill in **Pesan** (Message).
2. Fill in **Dari** (From) as the sender name on the image.
3. Fill in **Judul** (Title).
4. Check **Tanggal** (Date) and **Jam** (Time); the initial values follow your device's time when the form opened.
5. Press **Generate**.
6. Check the preview, then choose Download PNG or Copy URL.

Example:

- Pesan (Message): "Jangan lupa istirahat." ("Don't forget to rest.")
- Dari (From): "Nexora".
- Judul (Title): "Pengingat" ("Reminder").

## Understanding the result

Dari (From) is not an SMS destination number. Date and Time are text on the message display, not a sending schedule.

Use a short message so it fits the classic phone screen in the template. If you change the text, time, or name, Generate again before downloading.

Copy URL only copies the image link. If the image service hasn't responded yet or the result is empty, there's no new image to save yet.
