# Nexora Anime Discover

Browse anime illustrations and reaction GIFs from **Waifu.im** and **NEKOSBEST**. It offers a general gallery, search, filters, random results, and a saved list.

## Getting to know the menu

| Menu | Purpose |
| --- | --- |
| **Discover** | Browse the collection of available results. |
| **Illustrations** | Focus on illustrations. |
| **Reactions** | Browse reaction images or GIFs. |
| **Random** | Look for random variations. |
| **Saved** | See items you've saved on this device. |
| **All / Waifu.im / NEKOSBEST** | Choose which source to use. |

## Getting started

1. Open Anime Discover.
2. Leave the source on All to see general options, or choose one source.
3. Choose Illustrations if you want images, or Reactions if you're looking for reactions.
4. Search by anime, tag, or artist, as supported by the source.
5. Open an image to see its details.
6. Use the available save, open source, copy URL, or download actions.
7. Open Saved to find the items you marked again.

Example: for reaction GIFs, choose Reactions and NEKOSBEST, then pick an available reaction category. For portrait illustrations, try Waifu.im with the Portrait filter.

## Using Filters

| Filter | What it means |
| --- | --- |
| **Orientation** | The image's shape: Any, Portrait, Landscape, or Square-ish. |
| **Minimum resolution** | The minimum width and height in pixels. |
| **Animation** | All, still images, or animated. |
| **Sort** | Random, newest, or most saved, according to the source's data. |
| **Tags — Include** | Requires certain tags to be included. Choose a tag, then Add. |
| **Tags — Exclude** | Avoids certain tags. |
| **Artist** | Searches for an artist using the available Waifu.im data. |

Not every filter works the same way on both sources. Follow the options active on screen. If you run out of results after adding many filters, press **Reset filters**, then add conditions one at a time.

**Surprise Me** asks for a random pick. That is not the same as AI creating a new image.

## Image details and Saved

Details may include the artist, anime, source link, size, or category. Information the provider doesn't supply isn't automatically known to Nexora.

Saved stores a record of your picks in the browser, not necessarily a copy of the full image file. If the source changes or the link dies, the saved list doesn't guarantee the media can still load. Download the file separately if you need to keep it.

## Issues

If one source fails, choose the other source or try again after a pause. If downloads are restricted, open the image URL through the available action. Artist names and works still belong to the source; seeing an image in the gallery is not a statement that its license allows every use.
