# Anime to Real

Turns an anime illustration into a more realistic-looking image using an AI service. The result is the AI's interpretation, not a real photo of a person whose identity can be confirmed.

## Two ways to provide an image

**Image URL:** paste a link that opens the image file directly, then use Convert.

**Pilih Gambar** (Choose Image): upload a JPG, PNG, or WebP from your device. The original image limit is 12 MB before resizing.

Google Share links, Pinterest, or post pages often open a web page, not an image file. If a source like that fails, save an image you're allowed to use and choose it from your gallery.

## How to use it

1. Choose one of the input methods.
2. Check the preview to make sure the right image will be processed.
3. Press **Convert** once.
4. Wait for the AI to process it; this can take about a minute.
5. Check the result that appears.
6. Use Open Image, Download Result, or Copy Link if available.

Practice example: use a character illustration with a fairly clear face and a simple composition to see how the service interprets a realistic style.

## What to understand

Uploaded images are made lighter before being passed on. In the upload flow, the image is made **temporarily public for at most one hour** so the AI service can read it. Use images that are appropriate to send to that service.

The face, clothing, lighting, or background may change. This tool is not a way to prove what a fictional character "really" looks like in real life.

## If it fails

Make sure the file opens, its format is supported, and its size is within the limit. If a URL doesn't produce a preview but really is a correct public file link, the request can still be tried, as the page's message indicates.

If the service rejects the image or is unavailable, read the message and use material that complies with its terms. Avoid pressing Convert repeatedly while a request is still in progress.
