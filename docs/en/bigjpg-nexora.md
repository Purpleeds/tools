# Perbesar Gambar 4x (Enlarge Image 4x)

Enlarges photos or illustrations with a choice of **2× or 4×**. The tool's name says 4x, but you can still choose 2×.

## First steps

1. Choose one JPG, PNG, or WebP of at most **3 MB**.
2. Choose **Perbesaran: 2×** or **4×** (Enlargement).
3. Choose the matching **Jenis gambar** (Image type): Ilustrasi / anime (Illustration / anime) or Foto (Photo).
4. Open **Kurangi noise** (Reduce noise) if needed; start with **Rendah** (Low), as the form suggests.
5. Press **Perbesar gambar** (Enlarge image).
6. Wait for the Unggah (Upload), Proses (Process), and Selesai (Done) stages.
7. Drag the preview divider to see before and after.
8. Press **Download hasil** (Download result).

## Understanding the options

**2×** requests twice the source's width and height. **4×** requests four times. For example, a 500 × 500 image with 4× requests a 2000 × 2000 result; check the dimensions of the result actually shown.

**Ilustrasi / anime** (Illustration / anime) is the processing mode for line art or illustrations. **Foto** (Photo) is for camera photos.

**Noise** means specks or interference in the image. Choose Mati (Off), Rendah (Low), Sedang (Medium), Tinggi (High), or Auto. Stronger values can remove texture; don't choose High for every photo straight away.

## Results and issues

**Muat ulang hasil tanpa memproses ulang** (Reload result without reprocessing) tries to load the preview of a job that has already finished. Use it if processing finished but the result image failed to appear. This is different from starting a new enlargement.

**Salin link** (Copy link) copies the address of the available result. **Mulai ulang** (Start over) clears the job for the next image.

The tool works online; seeing only the source image doesn't mean the enlargement is done. If a file is rejected, check the 3 MB size limit and the format. If the service limits requests, wait as the message says.

Enlargement does not guarantee that original detail that isn't there can be brought back. Check text, faces, and lines before using the result.
