# Fake OVO

Creates an **OVO simulation image** (OVO is an Indonesian e-wallet) showing an amount you enter. The result is marked SIMULASI (SIMULATION) and is meant as a demo or entertainment image.

## How to use it

1. Open Fake OVO.
2. Fill in **Nominal simulasi** (Simulation amount) as a number.
3. Press **Generate**.
4. Wait for the source image to be available.
5. Check the amount and the SIMULASI marker.
6. Press **Download hasil** (Download result) if you want to save it.

Example: enter 100000 to create a display showing a simulated amount of one hundred thousand, in the format the template uses.

## Results and limits

This image doesn't move any balance, doesn't open an OVO account, and doesn't prove a payment. The form provides no money transfer process.

The amount written on the image comes only from your input. The simulation marker remains part of the result.

If the source service fails, Nexora shows a message and no new image is created. Wait for the service to be ready, then try again if you still need it.
