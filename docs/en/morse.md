# Morse Code

Converts text into Morse code, or reads Morse code back into text. The result updates as you type.

## Text to Morse

1. Choose **Teks → Morse** (Text → Morse).
2. Type letters or numbers.
3. Read the dots and dashes that appear right away.
4. Use **Salin Hasil** (Copy Result) to copy.
5. Press **Putar Suara** (Play Sound) if you want to hear it.
6. Adjust Kecepatan Putar (Playback Speed) from slow to fast if needed.

Example: **SOS** becomes **... --- ...**.

## Morse to text

1. Choose **Morse → Teks** (Morse → Text).
2. Enter dots and dashes.
3. Separate each letter with a space.
4. Use **/** to separate words.
5. Read the resulting text.

Example: **.... .- .-.. --- / -. . -..- --- .-. .-** reads as **HALO NEXORA** ("HELLO NEXORA").

## Things to note

Switching modes clears the input so text and code aren't mixed. Copy the work you need before switching modes.

The tool's dictionary covers Latin letters A–Z, digits 0–9, and the word separator. Unrecognized characters may turn into **?**.

The sound plays through the browser/device; it isn't sent to a radio or phone number. If you can't hear it, check the volume and audio permission after pressing the button.
