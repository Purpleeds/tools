# Quote Generator

Creates a monochrome quote image with the author's name. Specific words can be marked for highlighting using **square brackets**.

## How to use it

1. Fill in the quote in the main field.
2. If there's a part you want highlighted, wrap it in [ and ].
3. Fill in the author's name in the field provided.
4. Press **Buat Gambar** (Create Image).
5. Check the preview and how the lines break.
6. Press **Download Gambar** (Download Image).

Example quote:

> Tidak apa berjalan pelan, selama kamu [tetap melangkah]. ("It's okay to walk slowly, as long as you [keep moving].")

The part "tetap melangkah" ("keep moving") is the one that gets highlighted. The square brackets work as a style marker, not text to be drawn as part of the sentence.

## Results and adjustments

The result is downloaded as a monochrome **JPG**. If the text is too long or the layout isn't comfortable, shorten the sentence and create it again.

Changing the author or quote doesn't automatically update the earlier result image; press Buat Gambar (Create Image) again. This tool makes a design from the text you enter; it doesn't look up or verify who really said the quote.

For a Windows-style look, see [Windows Quotes](winquotes.md).
