# Logo Animate

Prepares a logo animation XML template for Alight Motion with accompanying text. The template includes sample media that you later replace in Alight Motion.

**The logo is not uploaded through this form.** Replacing the media happens after the XML is imported.

## How to use it from start to finish

1. Fill in **Teks pendamping** (Accompanying text), for example a brand name.
2. Choose **Warna teks** (Text color).
3. Choose a **Font template** from the available list.
4. Leave **Tambahkan teks ke template** (Add text to template) on if you want the text included.
5. Fill in the project name and file name if needed.
6. Press **Generate XML**, then download the available result.
7. Import the XML into Alight Motion.
8. Find the placeholder logo media in the resulting project.
9. Replace that media with your own logo image.
10. Play the project to check the size, position, and motion before exporting a video.

## Settings to understand

- **Teks pendamping** (Accompanying text): text that's placed in the template.
- **Font template:** a font provided by the template, not an upload of any font.
- **Tambahkan teks ke template** (Add text to template): if turned off, the accompanying text isn't added through this option.
- **Nama project Alight Motion** (Alight Motion project name): the name inside the project.
- **Nama file download** (Download file name): the name of the saved XML file.

The original template lasts about 8.33 seconds. The engine merges the template's parts into a single project XML, not three files you'd have to combine yourself. Save that XML and then check the imported result.

## Example and issues

For a shop logo, enter the text "TOKO NEXORA", Generate, then replace the default logo media with your shop's logo PNG in Alight Motion. If the imported result still shows the sample media, the media replacement step hasn't been done yet.

Result history is stored locally. If Download All starts several downloads, allow multiple downloads if the browser asks. This tool doesn't export MP4 directly; the final video is exported from Alight Motion.
