# User Guide for All Nexora Tools — Version 2

This guide is for people who are new to Nexora. Open a tool through the dashboard search, then follow the matching page. Button names are written as they appear in the interface so they're easy to find. Where the interface uses an Indonesian label, the guides keep that label and give an English translation in parentheses.

**Simple tools are explained briefly. Complex tools are explained step by step**, including mode choices, what the fields mean, example entries, how to use the results, and what to check when something fails.

## Start from what you need

Read [the guide to choosing a tool](PANDUAN_MEMILIH_TOOL.md) for example workflows from idea to result, such as making an AI poster, turning a logo into Alight Motion material, or working with PDFs.

The three most fully expanded guides:

- [Nexora AI Image](aiimage.md): Generate, Edit, Reference, Multi, Puter accounts, models, aspect ratios, Quality, and actions after a result.
- [Nexora Prompt Studio](promptgenerate.md): 18 workflows, reference roles, Basic/Advanced/Pro, targets, examples, and how to use prompts.
- [Nexora Placeholder Studio](placeholderstudio.md): Classic/Prompt, sizes, colors, seeds, export, public URLs, and the download limitation found during the audit.

## How to follow the guides

1. Start from the Getting started, First try, or first steps section on the tool's page.
2. Use the examples provided to learn the flow. Examples are practice material, not a promised successful output.
3. Keep the default settings at first if you don't understand the advanced options yet.
4. Once a result is available, read the saving or export section. Some tools produce images; others only produce instructions or data.
5. If a button isn't active yet, check the input requirements and the issues section before repeating the request.

On a phone, some panels may be below the preview or inside an extra menu. Look for the button/field name the guide mentions.

## Common terms

| Term | What it simply means |
| --- | --- |
| **Prompt** | A written instruction for an AI. |
| **Generate / Proses** (Process) | Runs the creation or processing; with online services this may use up the service's allowance. |
| **Reference** | An image or material used as a reference. |
| **Model / Engine** | The engine that does the job; each engine may support different options. |
| **Seed** | A number or text used as a variation reference; its range and effect depend on the tool. |
| **Aspect ratio / Rasio** (Ratio) | The ratio of width to height; for example, 9:16 means portrait. |
| **Preview** | A view for checking; it doesn't always mean the final file has been created. |
| **Export / Download** | Creates or saves the result file, depending on the button and tool. |
| **Layer** | A layer of an image or a project element that can be adjusted separately. |
| **Keyframe** | A marker for a value at a particular time in an animation. |
| **Mask** | A map of the parts of an image to keep or discard. |
| **Direct URL** | A link that opens the file directly, as opposed to a post page. |
| **Local / Cloud** | Processing on your device / processing on a service over the internet. |
| **PNG / JPG / WebP** | Ordinary image formats. |
| **SVG** | A vector, shape-based image. |
| **XML Alight Motion** | A project/shape file to import into Alight Motion, not a final video. |
| **MP4 / WAV / MP3** | Video / audio files. |
| **TXT / Markdown / JSON / CSV** | Ways of storing text or data, not automatically a result image. |

## Basis of the audit and limits of the guides

The guides refer to [Nexora source commit 25172f6](https://github.com/akidwush/dika-nexora-ganteng/tree/25172f69c8c68d6c5c0371a16db73301e09740ab), the candidate source used for the Vecto deployment in the conversation where these guides were written.

The audit went through the catalog, the frontend modules, the built-in apps opened through the launcher, and the relevant processing code. AI Image, Prompt Studio, and Placeholder were also opened in a local browser fixture to check the mode options and form requirements. No paid generation requests or real account verifications were made during the documentation audit.

Some important corrections compared with the earlier brief descriptions:

- AI Image has four modes, not just creating images from text.
- Prompt Studio produces instruction text, with 18 workflows and different reference requirements.
- In the version checked, Placeholder's Classic Download saves the SVG preview even when PNG is chosen as the Format; its guide explains the provider URL route and how it differs.
- Virus Scan uses local heuristics; a low-risk result is not proof of a cloud antivirus scan.
- BMKG weather requires an ADM4 village/ward code.
- Logo Animate builds a single project XML, and its logo media is replaced in Alight Motion.

Online features depend on the state of the services when used. Login access, quotas, and the available options still follow Nexora's or the provider's settings. Reading the guides is not proof that all external services are currently active.
