# Quote TikTok Nexora

Creates a TikTok-style message/quote image with a username, text, and photo of your choice. The result is a simulated image, not a message actually sent from a TikTok account.

## How to use it

1. Fill in the **username** you want to display.
2. Write the message in the text field.
3. Add a photo through the avatar picker if needed.
4. Press **GENERATE NEXORA QUOTE**.
5. Check the result preview.
6. Press **DOWNLOAD CHAT** to save the PNG.
7. Use RESET if you want to start with new input.

Example: username "nexora_demo" and the message "Terus belajar, satu langkah setiap hari." ("Keep learning, one step every day.")

## Understanding the result

The chosen photo becomes material for the image. Entering a username doesn't make Nexora log in to a TikTok account with that name.

Download saves an image, not a chat history from TikTok. If the text is too long or the line breaks aren't comfortable, shorten it and Generate again.

## If it doesn't work yet

Check that the requested username, message, and avatar have been filled in correctly. If the result hasn't appeared, don't press Download assuming the process is done.

Save the result before RESET or closing the tool. For a monochrome quote design without the chat look, use [Quote Generator](quotegenerator.md).
