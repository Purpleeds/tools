# Nexora AI Song Generator

Creates a song from a description of the idea, story, mood, vocals, and music style. The main field is a direction for the song, not just a singer's name or a single title.

## How to use it

1. Fill in **Describe your song**.
2. Fill in **Song Title** if you already have a title; this field is optional.
3. Fill in **Style / Genre**, or pick a chip: Pop, Rock, EDM, Lo-fi, Hip Hop, Emotional, or Cinematic.
4. Press **Generate Song** once.
5. Wait for processing to finish; it can take up to about two minutes.
6. Press Play on the resulting audio.
7. If it suits you, use Download Song, Open Audio, or Copy Link.

## An example description that helps more

> An Indonesian-language acoustic pop song about the journey home after an exhausting day. Warm and hopeful mood, soft vocals, acoustic guitar as the main instrument, relaxed tempo.

For example, enter the title "Jalan Pulang" ("The Way Home"), and the Style / Genre "acoustic pop, warm, mellow".

This is an example direction, not a guarantee that the provider will produce exactly a particular language, structure, or length. Add what matters most; don't just write "make a good song".

## Understanding the result

The player doesn't start automatically. If **Lyrics** appear, that text really was returned by the provider; a lyrics section isn't always available for every result.

**Download Song** fetches the existing result; it doesn't create a new song. **Open Audio** opens the audio address; use the browser's save option if direct downloads are restricted.

## If it hasn't finished

Wait for the final status before sending another request. If there's a problem with the quota or the service, read the message and try again once it's available. Save any audio you want to use before closing the tool; this page is not a permanent song library.

For text-reading narration or short sound effects, use [ElevenLabs Studio](elevenlabs.md).
