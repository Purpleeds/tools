# CariFakta (Find Facts)

Helps you examine claims or news using AI. Suitable for working out what needs to be checked in a message, a forwarded news item, or a social media post.

## How to use it

1. Open **CariFakta**.
2. Paste the claim or news into the text field; the limit is 2,000 characters.
3. Include the sentence you want checked, not just "is this true?".
4. Press **Cek Sekarang** (Check Now).
5. Read the detailed analysis and the claims found.
6. Check the explanation against the relevant original sources.
7. Use **Cek klaim lain** (Check another claim) for the next job.

Practice material:

> A message says all schools in this city are closed tomorrow. What information should be checked to assess that claim?

Mention the city, date, and source if known so the context isn't vague.

## Reading the result

**Klaim yang Ditemukan** (Claims Found) helps separate the statements being assessed. **Analisis Detail** (Detailed Analysis), **Topik Terkait** (Related Topics), and **Konteks** (Context) give extra explanation when available.

**Tingkat Keyakinan AI** (AI Confidence Level) is the system's own assessment, not proof that the claim has been verified by an official body. A confident answer can still be wrong or use context that doesn't fit.

## Results and issues

The available history helps you reopen earlier checks; Hapus semua (Delete all) clears that feature's history records.

If the text is too long, split it into clearer claims. If the service fails, read the message and try again when it's ready. Don't turn the AI's output into a quote from an official source if the system didn't provide that source.
