# NEXORA Motion Control

A directory of external AI services for motion transfer, character animation, or character replacement. Nexora helps you choose a service; the image/video work is done on the service's site that you open.

## How to use it

1. Open **NEXORA Motion Control**.
2. Choose the **All**, **Motion**, **Animation**, or **Replace** filter.
3. Read the description and notes on the service card.
4. Check the service's status and requirements.
5. Press **Open Tool** to open the provider's site in another tab.
6. Follow the forms and rules on that site.

## Choosing a type of service

| Filter | General purpose |
| --- | --- |
| **Motion** | Transferring a motion pattern to a character. |
| **Animation** | Creating character movement or animation. |
| **Replace** | Replacing a character, with the capabilities the service provides. |

Example: if you have a motion video and a character image, look for a Motion service that actually accepts both. Don't assume every service in the directory supports the same inputs.

## Reading the status

**Available** means the service is marked as available; **Busy** means busy; **Offline** means unavailable; **Status unknown** means its state isn't known yet. The directory status is not a guarantee that your account, quota, or job at the provider will succeed right away.

If there are no cards, change the filter or use Try again when the list fails to load. Accounts, costs, durations, and results depend on the external service.

This Nexora directory page has no button for uploading material and rendering motion directly. If you need video from a prompt through Puter in Nexora, see [AI Video Generator](aivideo.md).
