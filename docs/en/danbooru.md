# Danbooru Search

Search for anime illustrations using **tags**, which are words that label an image's content. The search doesn't run automatically as you type; press Search to run it.

## How to search

1. Fill in **Search tags**.
2. To begin, use **Mode: Safe**.
3. Press **Search**.
4. Open an image from the gallery to see the preview and information.
5. Use Open Image, Copy Image Link, or Download if those options are available on the result.

Example tag: **hatsune_miku**. Many character names use underscores in place of spaces. Try a single clear tag before building a long combination.

## Understanding the options

**Safe** is the starting option for results that are safe according to the source's rating. **NSFW** requests the other categories available in the integration and is still subject to the source's rules and Nexora's access.

Character names or tags must match the source's naming. Long sentences like an AI request don't automatically become an image-generation prompt; this tool searches for images that already exist.

## If the results are empty

Check the tag spelling, reduce the combination, and try a single character name. Not every result has a full image or complete metadata.

Downloads can depend on the source's links and restrictions. If an image link is available but a direct download doesn't work, use Open Image and then the browser's save option if supported.

To browse illustrations and GIFs from several sources, see [Anime Discover](animegallery.md).
