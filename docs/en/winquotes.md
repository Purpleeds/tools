# Windows Quotes

Creates Windows-style quote images with two display options. Text can be split into several lines using the **|** character.

## How to use it

1. Choose **Style 1** or **Style 2**.
2. Fill in the text field.
3. For several lines, separate the text with the | character.
4. Press **Generate**.
5. Check the image.
6. Press **Download PNG** or **Copy URL**.

Example entry:

> tetap belajar|pelan-pelan|yang penting|terus jalan ("keep learning|slowly|what matters|is to keep going")

The | character works as a line separator for this image service. Writing one sentence without it produces a different layout.

## Results and issues

The Style changes how the image looks, not its words. After switching Style, Generate again so the result follows your latest choice.

Copy URL copies the result's address; it doesn't save a file to your gallery. If you need a file, use Download PNG.

Generation uses an online provider. If the preview doesn't appear, check your connection or wait for the service to recover. Start with a short quote so the text is easier to read.
