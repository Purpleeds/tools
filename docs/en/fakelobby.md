# Fake Lobby

Creates an imitation Free Fire or Mobile Legends lobby image with a nickname of your choice. This feature makes an entertainment image; it doesn't change a real game lobby.

## How to use it

1. Choose **Free Fire** or **Mobile Legends**.
2. Fill in **Nickname**.
3. Press **Generate**.
4. Wait for the result image from the provider.
5. Press **Download PNG** once the image is available.

Example nickname: "NexoraDemo". Start with a short name so it isn't too long in the result.

## What you can and can't set

The main options are the game and the nickname. This is not a full editor for changing all players, statistics, inventory, or account details.

The template and other assets follow the image-generation service. The result doesn't prove that a game account with that nickname is in the state shown in the image.

## If it fails

If the image isn't visible yet, don't assume the Download button already has a new result. Check the status, choose the right game, then try again when the service is available.

After changing the nickname or game, press Generate again before saving. Save the image you want before closing the tool.
