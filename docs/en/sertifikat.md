# Sertifikat Custom (Custom Certificate)

Creates a meme certificate image with a name or text of your choice. Suitable for entertainment and parody content, not for issuing official certificates.

## How to use it

1. Open **Sertifikat Custom**.
2. Fill in **Nama / teks** (Name / text), for example a character's name or a humorous line.
3. Press **Generate**.
4. Wait for the image from the source service.
5. Check the text on the result.
6. Press **Download hasil** (Download result).

The name/text field is limited to 180 characters. Try short text first so it's easy to read on the certificate design.

## Example and result

Example entry: "Nexora Paling Rajin" ("Most Diligent Nexora"). The tool passes that text to the available certificate source; the result is an image, not a document of endorsement.

If the source service is offline, Nexora shows a failure. No image appearing means there's no result to download yet. Check the text and connection, then try again when the service is ready.

The template follows the original source. This form doesn't provide a full editor for designing the whole certificate yourself.
