# Cari Preset AM (Find AM Presets)

Finds links to Alight Motion presets or XML shared through TikTok videos. The tool looks for links that exist; it doesn't create a new preset just by reading the video's effects.

## How to use it

1. Open the TikTok video that shares the preset.
2. Copy its link through the Share menu.
3. Open **Cari Preset AM**.
4. Paste it into **Link video TikTok** (TikTok video link).
5. Press **Cari Preset** (Find Preset).
6. Wait for the check of the video information and related sources to finish.
7. Read the candidate links found, then copy or open the one that fits.

## Reading the results

Links may be found in the description, profile information, or comments available to check. Read the note on where a candidate came from when it's shown.

If there are several candidates, don't assume they're all the same preset. Some go to Alight Motion, an XML file, or an intermediate page.

## Example

Use a video whose creator says "preset is in the description". The tool tries to fetch the link actually written there, or related sources that can be accessed.

If the creator only wrote "check bio" but the link can't be read, the result may still be empty.

## If nothing is found

Not found means no candidate was fetched successfully in that process, not proof that the video doesn't use a preset. Check whether the video is still public, the link is complete, and the source account can be accessed.

This tool doesn't extract all keyframes from a TikTok video or guarantee a preset fits the Alight Motion version you use. Check candidates before importing.
