# Password Generator

Creates random passwords in the browser. This version of the form has a **length** setting, not a separate list of character-type options.

## How to use it

1. Slide **Panjang** (Length) to the number of characters you want, from 8 to 32.
2. Press **Generate**.
3. See the password in the result.
4. Press **Salin** (Copy).
5. Save it in a password manager or storage you control before closing the page.

To try it, use a length of 16 or more, as the target service's rules allow. The generator draws characters from a predefined set of lowercase letters, uppercase letters, digits, and symbols. A single random result doesn't guarantee that every category always appears.

## Results and issues

The next Generate creates a new password; the old result isn't automatically kept as a permanent archive.

If the target service forbids certain symbols, make sure the result meets its rules before using it. This tool doesn't change any account's password automatically.

If the browser refuses Salin (Copy), select the result text and copy it manually. If **Generator acak aman tidak tersedia** (Secure random generator not available) appears, use a modern browser over HTTPS; don't assume the tool has created a new result.
