# Nexora Auto PDF

Turns your writing into a PDF with automatic page breaks. Suitable for stories, notes, learning material, or writing with several sections.

## How to use it

1. Fill in the section title and paste its text.
2. Use **Tambah bagian** (Add section) if there's another chapter or section.
3. Choose **A5** or **A4** paper.
4. Choose the **Helvetica** or **Times Roman** font.
5. Adjust the font size, line spacing, and margins if needed.
6. Press **Buat Preview** (Create Preview).
7. Check the page and paragraph breaks.
8. Fill in **Nama file** (File name), then press **Unduh PDF** (Download PDF) once the preview is ready.

If you change the text or settings after creating the preview, create the preview again so the download matches the latest content.

## Choosing settings

| Option | Simple guide |
| --- | --- |
| **A5** | More compact pages, suited to reading material such as a small novel. |
| **A4** | Wider pages, common for documents. |
| **Helvetica** | A clean, modern typeface. |
| **Times Roman** | A more classic or formal look. |
| **Ukuran font** (Font size) | The text size; the form's range is 8–18. |
| **Jarak baris** (Line spacing) | The space between lines; larger values make reading more airy. |
| **Margin (pt)** | The empty space at the page edges. |
| **Mulai setiap bagian di halaman baru** (Start each section on a new page) | Makes each chapter or section start on its own page. |

## Example and result

Enter "BAB 1" (Chapter 1) as the title, fill in the story, then use Tambah bagian (Add section) for "BAB 2" (Chapter 2). Turn on a new page per section if you want each chapter to start separately.

The PDF is created on your device and the file can be downloaded right away. This tool lays out text; it doesn't analyze it with AI or copy the layout of an old PDF.

If there are characters the font can't handle, check the message and replace those characters or use supported text. Save the PDF before using Reset or closing the tool. To merge finished PDFs, use [PDF Lab Local](pdflab.md).
