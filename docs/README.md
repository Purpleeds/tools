# Panduan Pengguna Semua Tool Nexora — Versi 2

Panduan ini untuk orang yang baru memakai Nexora. Buka tool melalui pencarian dashboard, lalu ikuti halaman yang sesuai. Nama tombol ditulis seperti yang ada di antarmuka agar mudah ditemukan.

**Tool sederhana dijelaskan secukupnya. Tool yang rumit dijelaskan bertahap**, termasuk pilihan mode, arti kolom, contoh isian, cara menggunakan hasil, dan hal yang harus diperiksa saat gagal.

## Mulai dari kebutuhanmu

Baca [Panduan Memilih Tool](PANDUAN_MEMILIH_TOOL.md) untuk contoh alur dari ide sampai hasil, misalnya membuat poster AI, mengubah logo ke Alight Motion, atau mengolah PDF.

Tiga panduan yang diperluas paling lengkap:

- [Nexora AI Image](aiimage.md): Generate, Edit, Reference, Multi, akun Puter, model, rasio, Quality, dan aksi setelah hasil.
- [Nexora Prompt Studio](promptgenerate.md): 18 workflow, peran reference, Basic/Advanced/Pro, target, contoh, dan penggunaan prompt.
- [Nexora Placeholder Studio](placeholderstudio.md): Classic/Prompt, ukuran, warna, seed, ekspor, URL publik, dan keterbatasan unduhan yang ditemukan saat audit.

## Cara mengikuti panduan

1. Mulai dari bagian Cara mulai, Percobaan pertama, atau langkah awal pada halaman tool.
2. Gunakan contoh yang disediakan untuk mengenali alurnya. Contoh adalah bahan latihan, bukan keluaran sukses yang sudah dijanjikan.
3. Pertahankan pengaturan bawaan dahulu jika belum memahami pilihan lanjutan.
4. Setelah hasil tersedia, baca bagian penyimpanan atau ekspor. Ada tool yang menghasilkan gambar, ada yang hanya menghasilkan instruksi atau data.
5. Jika tombol belum aktif, lihat persyaratan masukan dan bagian kendala sebelum mengulang permintaan.

Pada HP, sebagian panel dapat berada di bawah preview atau di dalam menu tambahan. Cari nama tombol/kolom yang disebutkan panduan.

## Istilah yang sering ditemui

| Istilah | Arti sederhananya |
| --- | --- |
| **Prompt** | Instruksi berupa tulisan untuk AI. |
| **Generate / Proses** | Menjalankan pembuatan atau pengolahan; pada layanan online ini dapat memakai jatah layanan. |
| **Reference** | Gambar atau bahan acuan. |
| **Model / Engine** | Mesin yang menjalankan pekerjaan; tiap mesin dapat mendukung pilihan berbeda. |
| **Seed** | Angka atau teks acuan variasi; rentang dan pengaruhnya mengikuti tool. |
| **Aspect ratio / Rasio** | Perbandingan lebar dan tinggi, misalnya 9:16 berarti tegak. |
| **Preview** | Tampilan pemeriksaan; belum selalu berarti file akhir sudah dibuat. |
| **Export / Download** | Membuat atau menyimpan berkas hasil, sesuai tombol dan tool. |
| **Layer** | Lapisan gambar atau unsur proyek yang bisa diatur terpisah. |
| **Keyframe** | Penanda nilai pada waktu tertentu dalam animasi. |
| **Mask** | Peta bagian gambar yang dipertahankan atau dibuang. |
| **Direct URL** | Tautan yang membuka file langsung, berbeda dari halaman postingan. |
| **Local / Cloud** | Proses di perangkatmu / proses di layanan melalui internet. |
| **PNG / JPG / WebP** | Format gambar biasa. |
| **SVG** | Gambar berbasis bentuk vektor. |
| **XML Alight Motion** | Berkas proyek/bentuk untuk diimpor ke Alight Motion, bukan video final. |
| **MP4 / WAV / MP3** | Berkas video / audio. |
| **TXT / Markdown / JSON / CSV** | Bentuk penyimpanan tulisan atau data, bukan otomatis gambar hasil. |

## Dasar audit dan batas panduan

Panduan mengacu pada [source Nexora commit 25172f6](https://github.com/akidwush/dika-nexora-ganteng/tree/25172f69c8c68d6c5c0371a16db73301e09740ab), yaitu source kandidat yang dipakai pada deployment Vecto dalam percakapan ini.

Audit menelusuri katalog, modul frontend, aplikasi bawaan yang dibuka melalui launcher, dan kode pengolah yang relevan. AI Image, Prompt Studio, dan Placeholder juga dibuka dalam fixture browser lokal untuk memeriksa pilihan mode serta syarat formulir. Tidak ada permintaan generasi berbayar atau verifikasi akun nyata dalam audit dokumentasi.

Beberapa koreksi penting dibanding penjelasan ringkas sebelumnya:

- AI Image mempunyai empat mode, bukan hanya pembuatan gambar dari tulisan.
- Prompt Studio menghasilkan teks instruksi, dengan 18 workflow dan syarat reference yang berbeda.
- Download Classic Placeholder pada versi yang diperiksa menyimpan SVG preview meski Format dipilih PNG; panduannya menjelaskan jalur URL penyedia dan perbedaannya.
- Virus Scan memakai heuristik lokal; hasil risiko rendah bukan bukti pemindaian antivirus cloud.
- Cuaca BMKG memerlukan kode desa/kelurahan ADM4.
- Logo Animate menyusun satu XML proyek dan media logonya diganti di Alight Motion.

Fitur online mengikuti keadaan layanan saat digunakan. Akses login, kuota, dan pilihan yang tersedia tetap mengikuti pengaturan Nexora atau penyedianya. Membaca panduan bukan bukti semua layanan eksternal sedang aktif.
