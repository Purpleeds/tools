# Nexora Anime Discover

Menjelajahi ilustrasi anime dan GIF reaksi dari **Waifu.im** serta **NEKOSBEST**. Ada pilihan galeri umum, pencarian, filter, hasil acak, dan daftar tersimpan.

## Mengenali menu

| Menu | Kegunaan |
| --- | --- |
| **Discover** | Menjelajahi kumpulan hasil yang tersedia. |
| **Illustrations** | Berfokus pada ilustrasi. |
| **Reactions** | Menjelajahi gambar atau GIF reaksi. |
| **Random** | Mencari variasi hasil acak. |
| **Saved** | Melihat item yang pernah kamu simpan pada perangkat. |
| **All / Waifu.im / NEKOSBEST** | Memilih sumber yang digunakan. |

## Cara mulai

1. Buka Anime Discover.
2. Biarkan sumber All untuk melihat pilihan umum, atau pilih satu sumber.
3. Pilih Illustrations jika ingin gambar, atau Reactions jika mencari reaksi.
4. Gunakan pencarian anime, tag, atau artis sesuai dukungan sumber.
5. Buka satu gambar untuk melihat detail.
6. Gunakan aksi simpan, buka sumber, salin URL, atau unduh yang tersedia.
7. Buka Saved untuk menemukan kembali item yang ditandai.

Contoh: untuk GIF reaksi, pilih Reactions dan NEKOSBEST lalu pilih kategori reaksi yang tersedia. Untuk ilustrasi tegak, coba Waifu.im dan filter Portrait.

## Memakai Filters

| Filter | Artinya |
| --- | --- |
| **Orientation** | Bentuk gambar: Any, Portrait, Landscape, atau Square-ish. |
| **Minimum resolution** | Batas lebar dan tinggi minimum dalam piksel. |
| **Animation** | Semua, gambar diam, atau animasi. |
| **Sort** | Acak, terbaru, atau paling banyak disimpan menurut data sumber. |
| **Tags — Include** | Meminta tag tertentu disertakan. Pilih tag lalu Add. |
| **Tags — Exclude** | Menghindari tag tertentu. |
| **Artist** | Mencari artis sesuai data Waifu.im yang tersedia. |

Tidak semua filter berlaku dengan cara yang sama pada kedua sumber. Ikuti pilihan yang aktif di layar. Jika hasil habis setelah banyak filter, tekan **Reset filters**, lalu tambahkan syarat satu per satu.

**Surprise Me** meminta pilihan acak. Itu tidak sama dengan AI membuat gambar baru.

## Detail gambar dan Saved

Detail dapat memuat artis, anime, tautan sumber, ukuran, atau kategori. Informasi yang tidak diberikan penyedia tidak otomatis diketahui Nexora.

Saved menyimpan catatan pilihan di browser, bukan selalu salinan file gambar penuh. Jika sumber berubah atau link mati, daftar tersimpan tidak menjamin media tetap bisa dimuat. Unduh file secara terpisah jika perlu menyimpannya.

## Kendala

Jika satu sumber gagal, pilih sumber lain atau coba lagi setelah jeda. Jika download dibatasi, buka URL gambar melalui aksi yang tersedia. Nama artis atau hasil karya tetap mengikuti sumber; melihat gambar di galeri bukan pernyataan bahwa lisensinya bebas untuk semua penggunaan.
