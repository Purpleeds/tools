# Foto To Link

Mengunggah gambar ke penyimpanan publik lalu menghasilkan **direct URL**, yaitu tautan yang langsung membuka file gambar.

## Cara pakai

1. Pilih JPG, PNG, WebP, atau GIF maksimal **10 MB**.
2. Bisa melalui pemilih file, drag & drop, atau tempel gambar dari clipboard jika browser mendukung.
3. Periksa preview dan nama file.
4. Tekan **Upload & Buat Link**.
5. Tunggu sampai muncul pesan upload terverifikasi dan link hasil.
6. Tekan **Salin** untuk menyalin direct URL.
7. Gunakan **Buka gambar** untuk memeriksa tautannya.
8. **Upload lagi** menyiapkan gambar berikutnya.

Contoh: unggah gambar produk yang memang akan dibagikan, salin tautannya, lalu gunakan pada layanan yang meminta URL gambar langsung.

## Memahami status

Preview awal hanya menunjukkan file pilihan di perangkat. Itu **belum berarti file sudah berhasil diunggah**.

Link yang siap dipakai muncul setelah verifikasi upload. Jika timeout dan tombol berubah menjadi **Periksa Upload**, gunakan tombol tersebut untuk memeriksa keadaan pekerjaan sebelumnya sebelum mencoba upload baru.

## Batas dan hasil

Tautan hasil bersifat publik; orang yang memiliki URL dapat membuka gambarnya. Pilih gambar yang memang pantas dibagikan dengan cara tersebut.

**Salin** menyalin alamat, bukan mengirim gambar ke aplikasi lain. Jika clipboard ditolak, pilih teks URL dan salin lewat menu browser.

Jika ukuran atau format ditolak, pilih file yang sesuai. Jika verifikasi belum berhasil, jangan membagikan preview lokal sebagai link publik. Link yang valid harus membuka file dari layanan penyimpanan.
