        Page lock

        Turn an HTML page into a single file that only opens with a passphrase. Unlock files made here to get the page back.

        What do you want to do?
        0 / 12

        A few unrelated words work well, like harbor lamp quiet seven. There is no way to recover a forgotten passphrase.

        How it works

        The page is encrypted with AES-256-GCM. The key comes from your passphrase through PBKDF2-SHA-256 with 600,000 rounds, which makes guessing slow.

        You get one HTML file. Opening it shows a passphrase box. The right passphrase decrypts and shows the original page, in any modern browser, with no server.

        Anyone you give the passphrase to can read and copy the page once it's open.

        Locked file ready

        Keep your original HTML. The locked file can only be opened again with the passphrase.

        Unlocked page

        It's shown as code here, not run.

        Cut-out layers

        Split a character or object into separate transparent PNGs, one per piece, ready to animate in Alight Motion or any editor with layers. Parts that don't touch become separate pieces. Draw a cut line to split parts that do.

        Showing a sample character. Choose a PNG, JPG or WebP up to 20 MB, or drop one on the preview.
